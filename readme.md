# TrionesDev IotDB SpringBoot 

## 引用
```xml
<dependency>
    <groupId>com.trionesdev.iotdb</groupId>
    <artifactId>triones-iotdb-spring-boot-starter</artifactId>
</dependency>
```
## 配置说明
```properties
spring.iotdb.treeDialect= 是否使用树模型
spring.iotdb.tableDialect= 是否使用表模型
spring.iotdb.maxSize= 最大线程池
spring.iotdb.host= 主机名
spring.iotdb.port= 端口
spring.iotdb.nodeUrls=节点地址(多个节点时使用)
spring.iotdb.user=用户名
spring.iotdb.password=密码
spring.iotdb.database=数据库名称(表模式生效)
spring.iotdb.ttl=默认有效时间(表模式生效)

```
